- **MODI is now ATLAS.** New name, new icon, "Hey ATLAS" wake phrase (you can still rename your assistant any time). Your settings, notes, voices and start-at-login choice move over by themselves when you update; an assistant you had renamed keeps its name, and one still called MODI becomes ATLAS. The old MODI shortcuts, app and login item are removed. <!-- legacy-modi -->
- **First run now works with no file editing.** ATLAS finds (or creates) the Hermes API key, turns on Hermes' API server, restarts Hermes and checks it - then asks which AI you use: **ChatGPT, Claude, Grok, OpenRouter or a local model (Ollama)** - signs you in through Hermes and sends a test message. Change it later in Settings -> AI connection. If Hermes isn't installed, one click runs its official installer. The scary "Hermes unreachable" error is now a friendly "Connect Hermes / Fix it" card.
- **No more "Windows Script Host" pop-up.** The desktop icon, Start Menu entry and start-at-login now launch PowerShell directly (no Windows Script Host needed). ATLAS starts its bridge only if it is not already running, waits until it is ready, then opens the window - or brings the open one to the front. Updating repairs old shortcuts, including taskbar pins.
- Wake word (optional, off by default), the in-app updater and the Settings tabs are unchanged.
